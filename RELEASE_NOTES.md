# FuriousAntiCheat v2.3.2

Validación de mods de Valheim mediante GUID, versión y SHA-256, con catálogos de obligatorios y opcionales, modos Enforce/AuditOnly, reintentos y motivos detallados de rechazo.

Instalar la DLL en `BepInEx/plugins/FuriousAntiCheat/` en servidor y clientes. Configurar los catálogos del servidor según el README y reiniciar. Es necesario usar la misma DLL en ambos extremos.

El control depende de información declarada por el cliente y no constituye una garantía contra clientes manipulados. Consultar el README para requisitos, configuración, diagnóstico y limitaciones.
